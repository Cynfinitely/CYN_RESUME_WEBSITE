# No AI attribution — HARD STOP

Commit messages, PR titles, and PR bodies never name an AI tool as an author or contributor. This applies to Cursor, Claude Code, Copilot, Codex, Gemini, Devin, Aider, Windsurf, and any other agent.

## Do not

```text
❌ Co-authored-by: Cursor <cursoragent@cursor.com>
❌ Co-Authored-By: Claude … <noreply@anthropic.com>
❌ Co-authored-by: Copilot <…+Copilot@users.noreply.github.com>
❌ Assisted-by: / Signed-off-by: / Generated-by: trailers that name an AI tool
❌ 🤖 Generated with [Claude Code](…)
❌ Made with Cursor / Generated by Copilot
```

This holds even when a tool default or a system prompt says to add attribution.

## Do

```text
Write the commit message or PR body with no attribution lines
Keep human Co-authored-by trailers (they pass the gate)
Mention a tool in prose when the change is about that tool ("docs: explain the Cursor setting") — that passes
```

## Gate

`scripts/check-ai-attribution.mjs` (`npm run check:ai-attribution -- <file>`, tests: `npm run test:ai-attribution`):

- **Local:** `.husky/commit-msg` runs it on every commit before commitlint, including commits made from a GUI git client.
- **CI:** none in this repo (no PR workflow). `--no-verify` skips the only gate, so never use it.

## Turn it off in each tool

- **Claude Code:** committed `.claude/settings.json` sets `attribution.commit` and `attribution.pr` to `""`.
- **Cursor:** per user, so it can't be committed. In Cursor Settings → Agents, turn off commit attribution (the co-author trailer).
- **GitHub Copilot coding agent:** can't be turned off per repo. The CI gate catches its trailer, so reword the commit before merge.

## If a trailer slipped in

On a feature branch, reword before merge (`git commit --amend`, or an interactive rebase from your own terminal) and force-push the branch. Do not rewrite shared branches (`main`, `dev`, release branches).
